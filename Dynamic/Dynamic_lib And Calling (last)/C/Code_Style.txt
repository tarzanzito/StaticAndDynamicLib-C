Regras de Ouro de Naming e Estilo no C

Como vem do Java e C#, terá de reescrever a sua memória muscular para estes três pontos:

• snake_case absoluto: Esqueça o camelCase (Java) e o PascalCase (C#). 
Em C, funções, variáveis e ficheiros usam letras minúsculas separadas por underscore (ex: abrir_ficheiro, id_utilizador).

• Constantes e Macros: Sempre em maiúsculas (#define BUFFER_SIZE 1024).

• Declaração de Variáveis:
 No C clássico (C89), todas as variáveis locais devem ser declaradas logo no início da função, antes de qualquer código executável.
 Embora o C moderno (C99+) permita declará-las em qualquer lado (como no for (int i...)), o código de sistemas profissional prefere frequentemente o isolamento no topo para controlo estrito do stack.
